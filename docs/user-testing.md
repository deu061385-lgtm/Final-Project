# Stride 사용자 테스트 및 피드백 기록

## 1. 목적과 기준

Stride를 실제 사용자에게 사용하게 하고, 주요 사용 흐름의 문제와 AI 코칭의 유용성·안전성에 관한 의견을 수집한다. 최종 과제 기준은 **실사용자 최소 5명 이상 테스트 및 피드백 반영**이다.

이 문서에는 집계된 결과와 익명화된 의견만 기록한다. 이름, 이메일, Discord ID, 원본 응답, 건강·운동 관련 개인 식별 정보는 공개 저장소에 올리지 않는다.

## 2. 테스트 현황

- **테스트 대상:** 러닝 또는 다른 운동을 기록하고 AI 코칭을 이용하는 일반 사용자
- **목표 참여 인원:** 최소 5명
- **완료 참여 인원:** 설문 응답 시트 확인 후 기입
- **현황:** 완료 인원과 설문 응답 수를 대조하기 전이므로, 최소 5명 기준 충족 여부는 미확정
- **설문:** [Stride 사용성 평가 설문](https://docs.google.com/forms/d/e/1FAIpQLScB9AB4stYHdMjoTFXQrIjZbLJpvazmxIMvaB4yzyN7NmAlGg/viewform)
- **결과 자료:** 응답 시트 원본은 팀 내부에서만 관리하고, 이 문서에는 익명 집계만 반영

> Discord에서 테스트 의견을 낸 인원이 언급되었지만, 실제 완료 응답 수와 동일하다고 확인되지 않았다. 설문 시트에서 완료 응답을 집계한 뒤 위 인원과 결과를 갱신한다.

## 3. 테스트 절차

테스터에게 본인 계정으로 배포 앱에 접속해 사용하도록 안내한다. 로그인 또는 AI 데이터 전송에 동의하지 않은 사용자는 해당 기능을 건너뛰고 설문에 미사용으로 표시한다.

| ID | 확인 작업 | 확인할 결과 | 상태 |
| --- | --- | --- | --- |
| T-01 | Google 로그인 및 로그아웃 | 로그인 상태가 표시되고 재접속 시 계정 상태가 유지됨 | 설문 결과 집계 대기 |
| T-02 | 운동 기록 추가 및 기록 목록 확인 | 입력한 운동 기록이 표시되고 로그인 계정에서 다시 확인됨 | 설문 결과 집계 대기 |
| T-03 | AI 코치에 운동 회복 질문 | 동의가 있어야 요청되며, 관련 질문에는 코칭과 일반 식단 가이드가 표시됨 | 팀 계정 수동 확인 완료; 외부 사용자 검증 대기 |
| T-04 | 최근 운동 기록을 참고하는 질문 | AI가 필요하다고 판단하면 본인 기록을 조회하고, 화면에 조회 안내가 표시됨 | 팀 계정 수동 확인 완료; 외부 사용자 검증 대기 |
| T-05 | 운동·영양 질문과 참고 자료 확인 | 관련 자료가 검색될 때 답변 아래 원문 출처가 표시되고, 무관한 질문에는 출처를 억지로 붙이지 않음 | RAG 관련 질문에서 출처 표시 확인; 무관 질문의 프로덕션 확인 대기 |
| T-06 | 날짜 이동 후 운동 계획 추가·조회·삭제 | 선택 날짜의 계획 변경이 계정에 반영됨 | 설문 결과 집계 대기 |
| T-07 | AI 생성 안내와 개인정보 안내 확인 | AI 생성 가이드, 동의, 요청 한정 정보 사용이 이해됨 | 프로덕션 화면 확인; 외부 사용자 의견 집계 대기 |

## 4. 초기 피드백과 조치

아래 항목은 설문 응답 시트의 빈도 집계 전 Discord에서 공유된 초기 의견이다. 반복 횟수를 뜻하지 않으며, 최종 우선순위는 실제 응답을 집계한 후 정한다.

| 초기 의견 | 확인된 조치 또는 상태 |
| --- | --- |
| 운동 후 에너지·탄수화물·단백질·수분 관련 안내가 있으면 좋겠다 | 시스템 프롬프트에 일반적인 운동 영양 가이드를 추가하고, 구체적인 식단·칼로리 처방은 제외함 |
| AI 코치가 이전 답변을 바탕으로 후속 질문을 이어가면 좋겠다 | 대화 이력은 현재 저장·전달하지 않음. 후속 기능 후보로 남김 |
| 운동 종류와 세부 기록 항목이 더 다양했으면 좋겠다 | 활동 기록은 러닝·축구·기타와 RPE 중심. 근력 세트·횟수·중량 기록은 미구현 |
| 통증이 있는 사용자에게 세부 운동 루틴이 있으면 좋겠다 | 진단·재활 처방은 하지 않고, 통증 시 보수적인 안전 안내와 전문가 상담을 우선함 |
| 사진·동영상으로 자세를 확인하고 싶다 | 이미지·영상 분석과 업로드는 미구현. 모델 지원·개인정보·검증 범위가 커 후속 검토 항목 |
| 다음 날 기록을 이어서 보고 싶다 | 로그인 계정의 운동 기록과 목표·경험을 저장해 후속 코칭에 활용. 로그인 전 로컬 기록은 계정으로 가져와야 동기화됨 |
