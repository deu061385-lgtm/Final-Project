# Stride 사용자 테스트 및 피드백 기록

## 1. 목적과 기준

Stride를 실제 사용자에게 사용하게 하고, 주요 사용 흐름의 문제와 AI 코칭의 유용성·안전성에 관한 의견을 수집한다. 최종 과제 기준은 **실사용자 최소 5명 이상 테스트 및 피드백 반영**이다.

이 문서에는 집계된 결과와 익명화된 의견만 기록한다. 이름, 이메일, Discord ID, 원본 응답, 건강·운동 관련 개인 식별 정보는 공개 저장소에 올리지 않는다.

## 2. 테스트 현황

- **테스트 대상:** 러닝 또는 다른 운동을 기록하고 AI 코칭을 이용하는 일반 사용자
- **목표 참여 인원:** 최소 5명
- **완료 참여 인원:** 팀원 보고와 사용자 확인 기준 5명
- **확인된 설문 응답:** 팀원 보고 기준 총 5건. Google 응답 시트와 최종 대조 필요
- **현황:** 최소 5명 기준을 보고상 충족했으며, 응답 시트 대조 및 피드백 반영 결과 정리가 남아 있음
- **설문:** [Stride 사용성 평가 설문](https://docs.google.com/forms/d/e/1FAIpQLScB9AB4stYHdMjoTFXQrIjZbLJpvazmxIMvaB4yzyN7NmAlGg/viewform)
- **결과 자료:** 응답 시트 원본은 팀 내부에서만 관리하고, 이 문서에는 익명 집계만 반영

> 팀원 두 명이 각각 배포 앱 사용 및 설문 완료 인원 2명을 보고했고, 이후 추가 참여자 1명이 앱 사용과 설문을 모두 완료했다고 사용자가 확인했다. 익명 피드백의 개인별 매핑과 Google 응답 시트의 최종 대조는 남아 있다.

## 3. 테스트 절차

테스터에게 본인 계정으로 배포 앱에 접속해 사용하도록 안내한다. 로그인 또는 AI 데이터 전송에 동의하지 않은 사용자는 해당 기능을 건너뛰고 설문에 미사용으로 표시한다.

| ID | 확인 작업 | 확인할 결과 | 상태 |
| --- | --- | --- | --- |
| T-01 | Google 로그인 및 로그아웃 | 로그인 상태가 표시되고 재접속 시 계정 상태가 유지됨 | 설문 결과 집계 대기 |
| T-02 | 운동 기록 추가 및 기록 목록 확인 | 입력한 운동 기록이 표시되고 로그인 계정에서 다시 확인됨 | 팀원 보고 기준 5명 기록 기능 사용; 추가·재조회 세부 흐름은 응답 시트 대조 대기 |
| T-03 | AI 코치에 운동 회복 질문 | 동의가 있어야 요청되며, 관련 질문에는 코칭과 일반 식단 가이드가 표시됨 | 팀원 보고 기준 5명 AI 코치 사용; 응답 의견은 4절 참조 |
| T-04 | 최근 운동 기록을 참고하는 질문 | AI가 필요하다고 판단하면 본인 기록을 조회하고, 화면에 조회 안내가 표시됨 | 팀 계정 수동 확인 완료; 외부 사용자 도구 조회 여부는 미확인 |
| T-05 | 운동·영양 질문과 참고 자료 확인 | 관련 자료가 검색될 때 답변 아래 원문 출처가 표시되고, 무관한 질문에는 출처를 억지로 붙이지 않음 | RAG 관련 질문에서 출처 표시 확인; 무관 질문의 프로덕션 확인 대기 |
| T-06 | 날짜 이동 후 운동 계획 추가·조회·삭제 | 선택 날짜의 계획 변경이 계정에 반영됨 | 설문 결과 집계 대기 |
| T-07 | AI 생성 안내와 개인정보 안내 확인 | AI 생성 가이드, 동의, 요청 한정 정보 사용이 이해됨 | 프로덕션 화면 확인; 외부 사용자 의견 집계 대기 |

## 4. 초기 피드백과 조치

아래는 Discord의 초기 의견과 팀원이 전달한 총 5명 응답 요약을 익명화해 정리한 것이다. 응답 시트 원본과 대조한 항목별 빈도는 아직 없으며, 팀원 요약은 개인별 의견과 연결하지 않는다. 최종 우선순위는 응답 시트 집계 후 정한다.

| 초기 의견 | 확인된 조치 또는 상태 |
| --- | --- |
| 운동 후 에너지·탄수화물·단백질·수분 관련 안내가 있으면 좋겠다 | 일반적인 운동 영양 가이드를 추가함. 개인별 식단·칼로리 처방은 제공하지 않음 |
| AI 코치의 답변이 단순하고, 이전 답변을 바탕으로 후속 질문을 이어가고 싶다 | 저장된 목표·경험, 필요 시 최근 운동 기록 조회, 검색된 운동·영양 자료와 가이드를 코칭에 활용함. 대화 이력은 저장·전달하지 않아 연속 대화는 미구현이며, 만족도 개선 여부는 사용자 테스트에서 확인 필요 |
| 날짜별 운동 계획을 추가하고 일정에서 확인하고 싶다 | 설문 13번 의견을 반영해 2026-10-30 날짜별 계획 추가·조회·삭제를 구현함 (`32a5713`). 실제 사용자 흐름 검증은 설문 집계 대기 |
| 기록한 운동과 목표를 다음 날에도 이용하고 싶다 | 로그인 계정의 운동 기록과 목표·경험을 저장해 후속 코칭에 활용함. 로그인 전 기록은 계정으로 가져와야 동기화되며, 대화 이력은 저장하지 않음 |
| 코치 답변을 저장해 다른 기기에서도 이어 보고 싶다 | 여러 응답 요약에서 대화 저장 부재로 캡처와 다른 기기에서 이어보기가 어렵다는 의견이 있었음. 대화 이력 저장·동기화는 미구현이며 후속 기능 후보 |
| AI가 운동 기록을 바탕으로 계획하고 식단도 함께 안내해 편리했다 | 한 익명 응답에서 긍정 의견으로 보고됨. 사용자 만족도나 반복 빈도로 일반화하지 않음 |
| 데스크톱 화면에서 글자와 요소가 작고 여백이 많으며, 기록 선택지·예시가 불친절하다는 의견 | 2명 피드백 요약에 따라 데스크톱 글자·요소 크기를 키우고 여백을 줄이는 CSS 조정을 반영함. 기록 선택지·예시와 화면별 세부 개선은 응답 시트 대조 후 우선순위를 정하고 프로덕션에서도 확인 필요 |
| 기록할 운동 종류를 직접 추가하고 기록·계획 화면의 선택지를 통일하고 싶다 | 추가 응답 1명에게서 요청됨. 현재 기록은 러닝·축구·기타, 계획은 러닝·축구·근력·기타로 서로 다르며 사용자 정의 운동 종류는 미구현. 공통 운동 종류와 사용자 정의 허용 범위를 검토 항목으로 둠 |
| 운동 종류와 세부 기록 항목이 더 다양했으면 좋겠다 | 근력 세트·횟수·중량 기록은 미구현이며, 범위와 우선순위를 추가 의견 집계 후 판단 |
| 통증이 있는 사용자에게 세부 운동 루틴이 있으면 좋겠다 | 진단·재활 처방은 하지 않음. 통증 시 보수적인 안전 안내와 전문가 상담을 우선함 |
| 사진·동영상으로 자세를 확인하고 싶다 | 이미지·영상 분석 및 업로드는 미구현. 모델 지원, 개인정보 보호와 분석 검증이 필요해 후속 검토 항목으로 둠 |
| 웨어러블 기기와 연동하고 싶다 | 연동은 미구현. 기기별 연동·권한 처리와 데이터 검증 범위가 커 현재 MVP에서는 보류함 |

## 6. 현재 집계 (최종본 아님)

- **완료 참여 인원:** 팀원 보고와 사용자 확인 기준 5명; 최소 기준 충족 보고
- **설문 응답 수:** 팀원 보고 기준 5건; Google 응답 시트 대조 필요
- **주요 사용 흐름:** 운동 기록 및 AI 코치 사용으로 보고됨; 세부 완료 흐름은 응답 시트 대조 필요
- **초기 장점 의견:** 운동 기록 기반 계획과 일반 식단 안내가 편리했다는 응답 1건이 공유됨. 빈도 미확정
- **초기 개선 의견:** 대화 저장·기기 간 이어보기, 데스크톱 가독성·정보 밀도, 기록 입력 선택지·예시·운동 종류 직접 추가, 기록·계획 종류 통일, 일정·코치 UI 개선. 응답 시트에서 항목별 빈도 대조 필요
- **실제 반영한 변경:** 날짜별 운동 계획 추가·조회·삭제 (`32a5713`); 그 외 신규 의견 반영 여부는 집계 후 결정
- **미반영 항목과 이유:** 대화 이력 저장, 데스크톱 UI 개선, 사용자 정의 운동 종류와 기록·계획 종류 통일, 기록 세분화는 미구현. 안전·범위·일정을 고려해 우선순위 결정 예정
